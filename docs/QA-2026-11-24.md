### Found and fixed (third pass), live on production

| # | Severity | Finding |
|---|---|---|
| L1 | Low-medium | **push-send refuses ~5% of its cron runs.** 14 of 304 calls to `cron_secret_matches` in 24 h returned 401 `PGRST303` (JWT claims rejected). It is always the same `sb_secret_` key, which succeeds the other 290 times, so it looks like a platform-side token timing glitch. Each one is a 401 from push-send. The next run 15 minutes later catches up, so pushes arrive late rather than never. The same check sits in fx-daily, guest-digest and backup-weekly, where one refused run waits a day or a week. **Fixed:** `_shared/cronAuth.ts` (8 tests), used by all four. Only an error is retried, once after 400 ms; a wrong secret is final; two errors still refuse. |
| L2 | Low | No index on `country_profiles.updated_by`. **Fixed:** 00108 (+ rollback). Harness 644 PASS, 0 FAIL on 108 migrations. |
