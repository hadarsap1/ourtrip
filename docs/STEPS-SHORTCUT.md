# ספירת צעדים מהאייפון - מדריך הגדרה (2 דקות לטלפון)

לכל הורה, על האייפון שלו. דורש שהדגל `stepsCounter` דלוק ושמיגרציה 00042 ופונקציית `steps-ingest` קיימות.

## 1. יצירת קוד באפליקציה
עוד ← "ספירת צעדים מהאייפון" ← שם הטלפון ← "יצירת קוד לטלפון הזה".
הקוד מוצג **פעם אחת בלבד**. מעתיקים את הקוד ואת הכתובת.

## 2. אוטומציה בקיצורים (Shortcuts)
1. קיצורים ← אוטומציה ← + ← "שעה ביום" (Time of Day) ← 21:30, כל יום ← "הפעלה מיידית" (Run Immediately), לא "שאל לפני הפעלה".
2. "קיצור דרך חדש ריק" ← "חיפוש דגימות בריאות" (Find Health Samples): סוג = צעדים (Steps), תאריך התחלה = היום (Today).
3. "חישוב סטטיסטיקה" (Calculate Statistics) ← סכום (Sum).
4. "עיצוב תאריך" (Format Date) על התאריך הנוכחי, פורמט מותאם (Custom) `yyyy-MM-dd`.
5. "קבלת תוכן של כתובת" (Get Contents of URL): הכתובת מהאפליקציה. "הצג עוד" (Show More): Method = **POST** (GET מחזיר 405), Request Body = JSON.
6. "הוסף שדה חדש" (Add new field), שלוש פעמים:
   - טקסט (Text): מפתח `token`, ערך = הקוד (מדביקים).
   - מספר (Number): מפתח `steps`, ערך = המשתנה "סטטיסטיקה" (Statistics) - בוחרים אותו מעל המקלדת, מופיע כבועה כחולה. לא מקלידים מספר.
   - טקסט (Text): מפתח `date`, ערך = המשתנה "תאריך מעוצב" (Formatted Date), בועה כחולה.
   - טקסט (Text): מפתח `prev`, ערך = המשתנה "טקסט משולב" (Combined Text) מסעיף 6א למטה. **השלמה רטרואקטיבית** של 3 הימים הקודמים.
6א. השלמה רטרואקטיבית (לפני "קבלת תוכן של כתובת"):
   - "חזרה" (Repeat) 3 פעמים. בתוך הלולאה:
     - "שינוי תאריך" (Adjust Date): הפחתה (Subtract) של "אינדקס חזרה" (Repeat Index) ימים מ"התאריך הנוכחי" (Current Date).
     - "שינוי תאריך" על התוצאה: "התחלת היום" (Get Start of Day). זה "תחילת יום".
     - "שינוי תאריך" על "תחילת יום": הוספה (Add) של יום 1. זה "סוף יום".
     - "חיפוש דגימות בריאות": סוג = צעדים, תאריך התחלה "בין" (is between) "תחילת יום" ל"סוף יום".
     - "חישוב סטטיסטיקה" ← סכום.
   - אחרי "סיום חזרה": "שילוב טקסט" (Combine Text) על "תוצאות החזרה" (Repeat Results), מפריד = שורות חדשות (New Lines).
   - השורה הראשונה = אתמול, השנייה = שלשום, השלישית = לפני 3 ימים. יום בלי דגימות נשאר שורה ריקה ולא מוזיז את השאר. אפסים לא דורסים ספירה קיימת.
7. בדיקה: המפתחות באנגלית ובאותיות קטנות; ב-`steps` וב-`date` רואים בועה כחולה.
8. הרצה ידנית אחת ← אישור גישה לבריאות. באפליקציה מופיע "דיווח אחרון". אין? מוסיפים בסוף "הצג תוצאה" (Show Result) ומריצים שוב: תשובה תקינה היא `{"ok":true,...,"backfilled":["2026-11-01","2026-10-31",...]}` - הרשימה אומרת אילו ימים קודמים הושלמו.

## 3. גיבוי: עוד טריגרים (חובה בפועל)
iOS לא נותן לקיצור לקרוא נתוני בריאות כשהאייפון נעול. אם בשעה שנקבעה המסך נעול, הקיצור נכשל בשקט ולא נשלח כלום (ככה נפלו ימים באוקטובר, ומאז 31/10 לא הגיע אף דיווח).
לכן בונים את הקיצור **פעם אחת כקיצור רגיל** בשם "צעדים OurTrip" (סעיפים 2-6, בלשונית "קיצורים" ולא בתוך אוטומציה), ומפעילים אותו מכמה אוטומציות:
1. **שעה ביום** 21:30 (כמו קודם) ← פעולה אחת: "הפעל קיצור" (Run Shortcut) ← "צעדים OurTrip".
2. **אפליקציה** (App) ← "נפתחת" (Is Opened) ← בוחרים WhatsApp ו-OurTrip ← "הפעלה מיידית" ← "הפעל קיצור" ← "צעדים OurTrip". כשאפליקציה נפתחת הטלפון כבר פתוח, אז הקריאה מבריאות עובדת.
3. **מטען** (Charger) ← "מחובר" (Is Connected) ← "הפעלה מיידית" ← אותו קיצור. מכסה את הערב, כשמחברים לטעינה לפני השינה.
4. בכל אוטומציה: לכבות "הודע בעת הפעלה" (Notify When Run) כדי שלא יקפוץ באנר בכל פתיחה של וואטסאפ.

אין בעיה לשלוח הרבה פעמים ביום: כל שליחה מחליפה את הסכום של אותו יום (לא מוסיפה), ושליחות שקרובות מ-20 שניות זו לזו פשוט נדחות.
❌ אם האייפון בכל זאת נעול כשהטריגר רץ (למשל מטען בזמן שהמסך כבוי), השליחה הזו תיכשל, אבל הטריגרים האחרים ישלימו.

`date` לא חובה: בלעדיו השרת לוקח את התאריך של היום לפי UTC (בשעה 21:30 ובמדינות הטיול זה אותו יום).

## אבטחה
- הטלפון מחזיק רק את הקוד, לא מפתח של Supabase. בשרת נשמר רק hash (SHA-256).
- רק הורים. ילדים ואורחים לא רואים צעדים, וגם לא את הק"מ ברגל שמחושבים מהם (RLS, מיגרציה 00042).
- טלפון אבד: עוד ← "טלפונים מחוברים" ← ביטול. מתג חירום בשרת: `STEPS_INGEST=off`.
- דיווח חוזר מאותו טלפון תוך 20 שניות נדחה; צעדים 0-200,000; תאריך עד 3 ימים אחורה, וגם ההשלמה הרטרואקטיבית (`prev`) לא חורגת מזה. יום שנפל לפני יותר מ-3 ימים כבר לא יושלם.

❌ שמות הפעולות בעברית ב-iOS עשויים להיות מעט שונים בגרסאות שונות - השמות באנגלית בסוגריים הם המדויקים.
