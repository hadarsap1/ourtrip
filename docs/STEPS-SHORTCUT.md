# ספירת צעדים מהאייפון - מדריך הגדרה (2 דקות לטלפון)

לכל הורה, על האייפון שלו. דורש שהדגל `stepsCounter` דלוק ושמיגרציה 00042 ופונקציית `steps-ingest` קיימות.

## 1. יצירת קוד באפליקציה
עוד ← "ספירת צעדים מהאייפון" ← שם הטלפון ← "יצירת קוד לטלפון הזה".
הקוד מוצג **פעם אחת בלבד**. מעתיקים את הקוד ואת הכתובת.

## 2. אוטומציה בקיצורים (Shortcuts)
1. קיצורים ← אוטומציה ← + ← "שעה ביום" (Time of Day) ← 21:30, כל יום ← "הפעלה מיידית" (Run Immediately).
2. "קיצור דרך חדש ריק" ← "חיפוש דגימות בריאות" (Find Health Samples): סוג = צעדים (Steps), תאריך התחלה = היום (Today).
3. "חישוב סטטיסטיקה" (Calculate Statistics) ← סכום (Sum).
4. "עיצוב תאריך" (Format Date) על התאריך הנוכחי, פורמט מותאם `yyyy-MM-dd`.
5. "קבלת תוכן של כתובת" (Get Contents of URL): הכתובת מהאפליקציה, Method = POST, Request Body = JSON:
   - `token` (Text) = הקוד
   - `steps` (Number) = תוצאת הסטטיסטיקה
   - `date` (Text) = התאריך המעוצב
6. הרצה ידנית אחת ← אישור גישה לבריאות. באפליקציה מופיע "דיווח אחרון".

## אבטחה
- הטלפון מחזיק רק את הקוד, לא מפתח של Supabase. בשרת נשמר רק hash (SHA-256).
- רק הורים. ילדים ואורחים לא רואים צעדים (RLS, מיגרציה 00042).
- טלפון אבד: עוד ← "טלפונים מחוברים" ← ביטול. מתג חירום בשרת: `STEPS_INGEST=off`.
- דיווח חוזר מאותו טלפון תוך 20 שניות נדחה; צעדים 0-200,000; תאריך עד 3 ימים אחורה.

❌ שמות הפעולות בעברית ב-iOS עשויים להיות מעט שונים בגרסאות שונות - השמות באנגלית בסוגריים הם המדויקים.
