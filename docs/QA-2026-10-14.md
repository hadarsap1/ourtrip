# QA pass - 14/10/2026

Hadar asked for end-to-end QA on phone, tablet and desktop, a full security
pass (docs/SECURITY-CHECKS.md, "Full security pass") and a UX/UI review.

## How

Production build (`next build` + `next start`) against a Supabase stand-in
with role-shaped fixtures (a trip in Thailand and Vietnam, a story, an
episode with a guest's comment, a pending kid message, an expense, a
booking, a checklist). Playwright, Chromium.

- Roles: parent, kid (after the PIN), guest, signed-out visitor.
- Sizes: phone 390x844, Android tablet 800x1280, desktop 1440x900.
- Screens: every route the role can reach - 26 for a parent, 13 for a kid,
  8 for a guest, 4 signed out. 153 page loads per run.
- Per page: JavaScript errors and console errors, horizontal overflow, RTL,
  tap targets under 32px, text under 12px, error text on screen, where the
  role lands. Plus a screenshot of each, reviewed by hand in contact sheets.

## Results

| Check | Result |
|---|---|
| JavaScript / console errors | 0 / 153 |
| Horizontal scroll | 0 |
| `dir="rtl"` | every page |
| Text under 12px | none |
| Tap targets under 32px | 1 (a native date input) |
| Kid / guest land on their own screens | yes (kid home, route, wall; guest portal) |

## UX/UI findings and fixes

| Finding | Fix |
|---|---|
| The capture button floated over the last card at the end of long screens (itinerary, settings, podcast) | the scroller gets room under it while it is shown (`body[data-fab]`) |
| The capture button sat on the composer of the wall and the journal | hidden on those two screens |
| A kid or guest who reached a parent screen by URL (budget, documents, checklists...) saw an empty parent screen | `RoleGate`: "the screen is the parents'" with a way home (RLS already returned nothing; not a security boundary) |
| Stories and podcast looked like a second app (earlier today) | one system: handwriting for screen titles only (#111) |

Seen and left as is: the tablet shows the phone layout in a wider column
(below the 1024px desktop breakpoint) - consistent and readable; the
phrasebook shows a raw category key for categories it has no label for.

## Not covered here

Real devices (iPhone Safari, the Android tablet), real push delivery, the
microphone, offline mode on a device, the Resend invitation email. These need
the family's own phones.
